# code-review-graph (installed 2026-07-26, user scope)

Graph tools are `mcp__code-review-graph__*`. Graphs are prebuilt for all repos;
refresh with `code-review-graph update` (1-3s), not `build`.

**Always pass `detail_level="minimal"` to `get_impact_radius_tool` and
`get_review_context_tool`.** The default (`"standard"`) dumps a full JSON record
per impacted node — measured at 26,633 tokens vs 129 tokens for `"minimal"` on a
25-line file (206x). The default defeats the entire purpose of the tool.

Prefer the cheap targeted tools (~100-400 tokens each):
`query_graph_tool` (callers_of / callees_of / tests_for / importers_of /
file_summary), `semantic_search_nodes_tool`, `get_minimal_context_tool`.
Reach for `impact`/`review_context` only when the blast radius is the question.

Treat CALLS edges as leads, not ground truth — they are tree-sitter + name
resolution, so dynamic dispatch and DI wiring are approximate. Verify by reading
the code before acting on an edge.
